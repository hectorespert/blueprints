## Tests

Run tests with pip in a local virtual environment:

1. Create and activate a virtual environment.
2. Install dependencies from requirements-test.txt.
3. Run pytest.

Example:

python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-test.txt
pytest -q
